# Documentation Directory

Folder ini adalah pusat sumber informasi (Single Source of Truth) untuk segala hal terkait perancangan, arsitektur, dan kebutuhan proyek NovaCMS.

## 📂 Struktur Dokumen

- `/prd` (Product Requirement Documents) - Berisi penjelasan fitur, target user, dan scope dari produk.
- `/architecture` - Berisi diagram infrastruktur, desain sistem, dan alur aplikasi (flowcharts).
- `/database` - Berisi desain skema database (ERD) dan catatan terkait migrasi data.
- `/api` - Dokumentasi end-points, API contracts (misal: Swagger/Postman collections).
- `/roadmap` - Timeline proyek, milestone, dan target rilis ke depannya.

Pastikan untuk **selalu memperbarui** dokumen di sini setiap kali ada perubahan arsitektur atau penambahan fitur besar.
